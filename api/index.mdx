# API REST

La API REST del plugin PlanetaDelEste.GW proporciona acceso programático a todas las funcionalidades del sistema. Está construida siguiendo los principios RESTful y utiliza autenticación JWT.

## Información General

- **Base URL**: `https://tu-dominio.com/api/v1/gw`
- **Protocolo**: HTTPS
- **Formato**: JSON
- **Autenticación**: JWT (JSON Web Token)
- **Rate Limiting**: 600 requests por minuto

## Autenticación

### Obtener Token JWT
```http
POST /api/v1/auth/login
Content-Type: application/json

{
    "email": "usuario@empresa.com",
    "password": "contraseña"
}
```

### Respuesta
```json
{
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "token_type": "bearer",
    "expires_in": 3600,
    "user": {
        "id": 1,
        "name": "Usuario",
        "email": "usuario@empresa.com"
    }
}
```

### Usar Token
```http
GET /api/v1/gw/invoices
Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...
Accept: application/json
```

## Operaciones CRUD

### Listar Recursos
```http
GET /api/v1/gw/invoices
```

**Parámetros de consulta:**
- `page`: Número de página (default: 1)
- `limit`: Registros por página (default: 20, max: 100)
- `sort`: Campo para ordenar (default: id)
- `order`: Dirección (asc/desc, default: desc)
- `search`: Término de búsqueda
- `filter[campo]`: Filtros específicos

**Ejemplo:**
```http
GET /api/v1/gw/invoices?page=2&limit=50&sort=created_at&order=desc&search=factura&filter[status]=active
```

### Obtener Recurso Específico
```http
GET /api/v1/gw/invoices/{id}
```

**Parámetros:**
- `include`: Relaciones a incluir (ej: `positions,customer`)

**Ejemplo:**
```http
GET /api/v1/gw/invoices/123?include=positions,customer,invoice_type
```

### Crear Recurso
```http
POST /api/v1/gw/invoices
Content-Type: application/json

{
    "company_id": 1,
    "customer_id": 100,
    "invoice_type_id": 1,
    "currency_id": 1,
    "order_serial": "A",
    "description": "Nueva factura",
    "positions": [
        {
            "item_id": 50,
            "item_type": "Product",
            "name": "Producto XYZ",
            "quantity": 2,
            "price": 100.00
        }
    ]
}
```

### Actualizar Recurso
```http
PUT /api/v1/gw/invoices/{id}
Content-Type: application/json

{
    "description": "Factura actualizada",
    "due_date": "2024-12-31"
}
```

### Eliminar Recurso
```http
DELETE /api/v1/gw/invoices/{id}
```

```json
    "errors": {

        "invoice_type_id": ["El tipo de factura es inválido"]

```

## Códigos de Estado HTTP

| Código | Significado | Descripción |
|--------|-------------|-------------|
| `200` | OK | Operación exitosa |
| `201` | Created | Recurso creado exitosamente |
| `204` | No Content | Operación exitosa sin contenido |
| `400` | Bad Request | Petición malformada |
| `401` | Unauthorized | Token inválido o expirado |
| `403` | Forbidden | Sin permisos para la operación |
| `404` | Not Found | Recurso no encontrado |
| `422` | Unprocessable Entity | Error de validación |
| `429` | Too Many Requests | Límite de rate exceeded |
| `500` | Internal Server Error | Error del servidor |

## Rate Limiting

### Límites por Default
- **Authenticated**: 600 requests por minuto
- **Guest**: 60 requests por minuto

### Headers de Rate Limit
```http
X-RateLimit-Limit: 600
X-RateLimit-Remaining: 599
X-RateLimit-Reset: 1640995200
```

### Respuesta cuando se excede el límite
```json
{
    "success": false,
    "message": "Too Many Attempts.",
    "code": 429
}
```

## Webhook Integration

### Configurar Webhook
```http
POST /api/v1/gw/webhooks
Content-Type: application/json

{
    "url": "https://mi-sistema.com/webhook",
    "events": ["invoice.signed", "invoice.cancelled"],
    "secret": "mi-secreto-webhook"
}
```

### Eventos Disponibles
- `invoice.created`
- `invoice.updated`
- `invoice.signed`
- `invoice.cancelled`
- `customer.created`
- `customer.updated`
- `balance.updated`

## SDK y Clients

### JavaScript/Node.js
```javascript
const GWApi = require('@planetadeleste/gw-api-client');

const api = new GWApi({
    baseURL: 'https://tu-dominio.com/api/v1/gw',
    token: 'tu-jwt-token'
});

// Crear factura
const invoice = await api.invoices.create({
    company_id: 1,
    customer_id: 100,
    invoice_type_id: 1
});

// Listar facturas
const invoices = await api.invoices.list({
    page: 1,
    limit: 20,
    include: 'customer,positions'
});
```

### PHP
```php
use PlanetaDelEste\GWApiClient\Client;

$client = new Client([
    'base_url' => 'https://tu-dominio.com/api/v1/gw',
    'token' => 'tu-jwt-token'
]);

// Crear cliente
$customer = $client->customers()->create([
    'name' => 'Nuevo Cliente',
    'email' => 'cliente@email.com',
    'company_id' => 1
]);

// Obtener facturas
$invoices = $client->invoices()->list([
    'filter' => ['status' => 'signed'],
    'include' => 'customer,positions'
]);
```
