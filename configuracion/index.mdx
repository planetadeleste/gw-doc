# Configuración

El plugin PlanetaDelEste.GW ofrece múltiples opciones de configuración para adaptarse a diferentes necesidades empresariales y regionales. La configuración se maneja a través de archivos, base de datos y la interfaz de administración.

## Estructura de Configuración

### Archivos de Configuración
- **config/config.php**: Configuraciones base del plugin
- **lang/**: Archivos de traducción e idiomas
- **plugin.yaml**: Configuración del plugin para OctoberCMS

### Configuraciones en Base de Datos
- **Settings**: Configuraciones globales del sistema
- **CompanySettings**: Configuraciones específicas por empresa
- **Modules**: Habilitación/deshabilitación de módulos

## Configuraciones Fiscales

### Cláusulas de Venta (ClauVenta)

Las cláusulas de venta según normativas internacionales:

```php
'sell_clause' => [
    'EXW',  // Ex Works
    'FAS',  // Free Alongside Ship
    'FOB',  // Free On Board
    'FCA',  // Free Carrier
    'CFR',  // Cost and Freight
    'CIF',  // Cost Insurance and Freight
    'CPT',  // Carriage Paid To
    'CIP',  // Carriage and Insurance Paid to
    'DAT',  // Delivered At Terminal
    'DAP',  // Delivered At Place
    'DDP',  // Delivered Duty Paid
    'N/A',  // No Aplica
]
```

**Uso en facturas:**
```php
$invoice = new Invoice([
    'sell_clause' => 'FOB',  // Free On Board
    // ... otros campos
]);
```

### Modalidades de Venta (ModVenta)

```php
'sell_mode' => [
    1,  // Régimen General
    2,  // Consignación
    3,  // Precio Revisable
    4,  // Bienes propios a exclaves aduaneros
    90, // Otras transacciones
]
```

**Configuración por defecto:**
```php
$invoice = new Invoice([
    'sell_mode' => 1,  // Régimen General
    // ... otros campos
]);
```

### Vías de Transporte (ViaTransp)

```php
'transport' => [
    1, // Marítimo
    2, // Aéreo
    3, // Terrestre
    9, // Otro
]
```

## Configuración de Módulos

### Habilitación de Funcionalidades

```php
// Verificar si un módulo está habilitado
if (Module::isEnabled('electronic_invoicing')) {
    // Procesar firma electrónica
    $invoice->sign();
}

if (Module::isEnabled('multi_currency')) {
    // Aplicar tipo de cambio
    $invoice->applyExchangeRate();
}
```

### Módulos Disponibles

| Módulo | Descripción | Dependencias |
|--------|-------------|--------------|
| `electronic_invoicing` | Facturación electrónica | Certificados digitales |
| `multi_currency` | Soporte multi-moneda | Cotizaciones actualizadas |
| `inventory_control` | Control de inventario | Productos configurados |
| `advanced_accounting` | Contabilidad avanzada | Plan de cuentas |
| `customer_portal` | Portal de clientes | API habilitada |
| `reporting_suite` | Suite de reportes | Permisos configurados |

## Configuración de Cache

### Estrategias de Cache

```php
// config/cache.php
'stores' => [
    'gw_invoices' => [
        'driver' => 'redis',
        'connection' => 'default',
        'prefix' => 'gw_invoices:',
    ],

    'gw_reports' => [
        'driver' => 'file',
        'path' => storage_path('cache/gw_reports'),
    ],
]
```

### Cache en Modelos

```php
// Configuración por modelo
class Customer extends Model
{
    use QueryCacheable;

    public $cacheFor = 7200; // 2 horas
    public $cacheTags = ['customers'];

    // Cache invalidation
    protected static function boot()
    {
        parent::boot();

        static::saved(function ($model) {
            Cache::tags(['customers'])->flush();
        });
    }
}
```

    gw-invoices-sign:
        label: 'Firmar facturas electrónicamente'

### Validaciones de Seguridad

```php
class InvoiceController extends Controller
{
    public function __construct()
    {
        parent::__construct();

        // Verificar permisos específicos
        $this->middleware(function ($request, $next) {
            if (!BackendAuth::getUser()->hasPermission('gw-invoices-view')) {
                throw new ForbiddenException();
            }
            return $next($request);
        });
    }
}
```
