# Modelo Invoice

El modelo `Invoice` es el núcleo del sistema de facturación del plugin PlanetaDelEste.GW. Representa todos los tipos de comprobantes fiscales y comerciales del sistema.

## Información General

- **Namespace**: `PlanetaDelEste\GW\Models\Invoice`
- **Tabla**: `invoices`
- **Clave Primaria**: `id`
- **Timestamps**: Sí
- **Soft Deletes**: Sí
- **Auditable**: Sí

## Eventos del Modelo

```php
public function beforeCreate()
{
    // Generar número automático si no se especifica
    if (!$this->order_number) {
        $this->generateOrderNumber();
    }

    // Establecer tipo de cambio actual
    if (!$this->rate && $this->currency_id) {
        $this->setCurrentExchangeRate();
    }
}

public function afterSave()
{
    // Actualizar datos planos
    $this->updateFlatData();

    // Recalcular totales
    $this->recalculateTotals();
}

public function beforeDelete()
{
    // Validar que se puede eliminar
    if ($this->is_signed) {
        throw new ValidationException(['invoice' => 'No se puede eliminar un comprobante firmado']);
    }
}
```

## Métodos Principales

### Gestión de Estado
```php
// Firmar comprobante electrónicamente
public function sign(): bool
{
    return $this->processElectronicSignature();
}

// Anular comprobante
public function cancel(string $reason = null): bool
{
    $this->cancelled_at = now();
    $this->flag = 'cancelled';
    $this->error_msg = $reason;
    return $this->save();
}

// Verificar si está firmado
public function isSigned(): bool
{
    return !empty($this->sign_at) && !empty($this->id_cae);
}
```

## Ejemplos de Uso

### Crear Nueva Factura
```php
$invoice = new Invoice([
    'company_id' => 1,
    'customer_id' => 100,
    'invoice_type_id' => 1,
    'currency_id' => 1,
    'order_serial' => 'A',
    'description' => 'Venta de productos'
]);

$invoice->save();

// Agregar líneas de detalle
$invoice->positions()->create([
    'product_id' => 50,
    'quantity' => 2,
    'unit_price' => 100.00
]);
```

### Consultar Facturas
```php
// Facturas del cliente
$customerInvoices = Invoice::where('customer_id', 100)
    ->with(['positions', 'customer'])
    ->orderBy('created_at', 'desc')
    ->get();

// Facturas pendientes de firma
$pendingInvoices = Invoice::pending()
    ->whereNull('sign_at')
    ->get();
```

### Procesar Firma Electrónica
```php
$invoice = Invoice::find(1);

if ($invoice->sign()) {
    // Firma exitosa
    $invoice->generatePdf();
    $invoice->sendByEmail($invoice->customer->email);
} else {
    // Error en firma
    Log::error('Error al firmar factura: ' . $invoice->error_msg);
}
```

## Consideraciones Especiales

<Warning>
**Facturas Firmadas**: Una vez firmada electrónicamente, una factura no puede ser modificada ni eliminada.
</Warning>

<Info>
**Numeración**: El sistema maneja la numeración automática por serie y tipo de comprobante.
</Info>

<Tip>
**Performance**: Usa el modelo `InvoiceFlat` para consultas que no requieren relaciones complejas.
</Tip>

---

El modelo Invoice es fundamental en el sistema y debe manejarse con cuidado, especialmente en lo referente a la firma electrónica y la trazabilidad fiscal.
