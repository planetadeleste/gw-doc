# Modelo InvoicePosition

El modelo `InvoicePosition` representa cada línea de detalle de una factura o comprobante. Maneja productos, servicios, descuentos e impuestos aplicados a cada ítem.

## Información General

- **Namespace**: `PlanetaDelEste\GW\Models\InvoicePosition`
- **Tabla**: `invoice_positions`
- **Clave Primaria**: `id`
- **Timestamps**: Sí
- **Auditable**: No (hereda auditoría de Invoice)

## Accessors y Mutators

### Accessors (Getters)

```php
// Precio unitario final
public function getUnitPriceAttribute(): float
{
    return MoneyHelper::round($this->price * $this->quote);
}

// Precio unitario sin impuestos
public function getUnitPriceWithoutTaxAttribute(): float
{
    $price = $this->unit_price;
    if ($this->tax_percent > 0) {
        $price = $price / (1 + ($this->tax_percent / 100));
    }
    return MoneyHelper::round($price);
}

// Total sin impuestos
public function getTotalWithoutTaxAttribute(): float
{
    return MoneyHelper::round($this->unit_price_without_tax * $this->quantity);
}

// Total de impuestos
public function getTotalTaxAttribute(): float
{
    return MoneyHelper::round($this->total_with_tax - $this->total_without_tax);
}

// Total con impuestos
public function getTotalWithTaxAttribute(): float
{
    return MoneyHelper::round($this->unit_price * $this->quantity);
}

// Precio con descuentos aplicados
public function getPriceWithDiscountsAttribute(): float
{
    $price = $this->unit_price;
    $discounts = $this->discounts->sum('amount');
    return MoneyHelper::round($price - $discounts);
}
```

## Eventos del Modelo

```php
public function beforeSave()
{
    // Establecer cotización si no está definida
    if (!$this->quote && $this->currency_id) {
        $this->setCurrentQuote();
    }

    // Copiar información del ítem si está disponible
    if ($this->item && !$this->name) {
        $this->copyItemData();
    }
}

public function afterSave()
{
    // Actualizar totales de la factura padre
    if ($this->invoice) {
        $this->invoice->recalculateTotals();
    }
}

public function beforeDelete()
{
    // Eliminar descuentos asociados
    $this->discounts()->delete();
}
```

## Métodos Principales

### Cálculos de Precios

```php
// Calcular precio base
public function calculateBasePrice(): float
{
    return $this->price * $this->quote;
}

// Aplicar descuentos
public function applyDiscounts(): float
{
    $price = $this->unit_price;
    $totalDiscounts = $this->discounts->sum('amount');
    return max(0, $price - $totalDiscounts);
}

// Calcular impuestos
public function calculateTax(): float
{
    $basePrice = $this->price_with_discounts;
    if ($this->tax_percent > 0) {
        return $basePrice * ($this->tax_percent / 100);
    }
    return 0;
}
```

### Gestión de Descuentos

```php
// Agregar descuento
public function addDiscount(float $amount, string $type = 'amount'): Discount
{
    return $this->discounts()->create([
        'amount' => $amount,
        'type' => $type,
        'description' => 'Descuento aplicado'
    ]);
}

// Eliminar descuentos
public function clearDiscounts(): int
{
    return $this->discounts()->delete();
}
```

### Utilidades

```php
// Copiar datos del ítem asociado
public function copyItemData(): void
{
    if (!$this->item) return;

    $this->name = $this->item->name;
    $this->description = $this->item->description ?? '';

    if (method_exists($this->item, 'getPrice')) {
        $this->price = $this->item->getPrice();
    }
}

// Validar cantidad disponible
public function validateStock(): bool
{
    if (!$this->item || !method_exists($this->item, 'getStock')) {
        return true; // No hay control de stock
    }

    return $this->item->getStock() >= $this->quantity;
}
```

## Consideraciones Especiales

<Warning>
**Cálculos de Precios**: Los cálculos se realizan considerando la cotización de la moneda al momento de la creación.
</Warning>

<Info>
**Descuentos**: Los descuentos se pueden aplicar tanto a nivel de posición como globalmente en la factura.
</Info>

<Tip>
**Performance**: Para consultas masivas, usa eager loading con las relaciones necesarias.
</Tip>

## Fórmulas de Cálculo

### Precio Final
```
precio_final = (precio_base * cotización) - descuentos
```

### Impuestos
```
impuesto = precio_con_descuentos * (porcentaje_impuesto / 100)
```

### Total por Línea
```
total = (precio_final + impuesto) * cantidad
```

---

El modelo InvoicePosition es crucial para el cálculo preciso de totales y la aplicación correcta de impuestos y descuentos en el sistema de facturación.
