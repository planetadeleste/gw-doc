# Comandos de Consola

El plugin PlanetaDelEste.GW incluye una serie de comandos Artisan para automatizar tareas administrativas, mantenimiento y migración de datos. Estos comandos están diseñados para ejecutarse desde la línea de comandos o programarse como tareas.

## Estructura General

Todos los comandos extienden `Illuminate\Console\Command` e implementan el trait `CommandTrait` para funcionalidades comunes:

```php
use Illuminate\Console\Command;
use PlanetaDelEste\GW\Traits\Console\CommandTrait;

class ExampleCommand extends Command
{
    use CommandTrait;

    protected $signature = 'gw:example {argument} {--option=default}';
    protected $description = 'Descripción del comando';

    public function handle(): void
    {
        // Lógica del comando
    }
}
```

## Parámetros Comunes

### Argumentos Estándar
```bash
# ID de empresa (opcional en la mayoría de comandos)
php artisan gw:comando {company_id}

# Procesar empresa específica
php artisan gw:update.balance 1
```

### Opciones Globales
```bash
# Tamaño de lote para procesamiento
--chunk-size=500

# Límite de memoria
--memory-limit=512M

# Modo silencioso (sin salida)
--quiet

# Modo verboso
-v, -vv, -vvv

# Forzar ejecución sin confirmación
--force

# Modo de prueba (dry-run)
--dry-run
```

## Configuración de Memoria y Performance

### Optimización de Memoria
```bash
# Para comandos que procesan grandes volúmenes
php artisan gw:update.balance --chunk-size=100 --memory-limit=256M

# Para servidores con recursos limitados
php artisan gw:migrate.from-pgsql --chunk-size=50 --memory-limit=128M
```

### Procesamiento por Lotes
```php
// Configuración típica en comandos
protected $chunkSize = 500;
protected $memoryLimit = '512M';

public function handle(): void
{
    if ($this->option('memory-limit')) {
        ini_set('memory_limit', $this->option('memory-limit'));
    }

    set_time_limit(0); // Sin límite de tiempo

    Model::chunk($this->option('chunk-size', $this->chunkSize), function ($records) {
        $this->processRecords($records);
    });
}
```

## Logging y Monitoreo

### Registro de Actividad
```php
public function handle(): void
{
    $this->info('Iniciando comando...');

    try {
        $this->processData();
        $this->info('Comando ejecutado exitosamente');
    } catch (Exception $e) {
        $this->error('Error: ' . $e->getMessage());
        Log::error('Error en comando', ['exception' => $e]);
        return 1;
    }

    return 0;
}
```

### Barras de Progreso
```php
$records = Model::all();
$progressBar = $this->output->createProgressBar($records->count());
$progressBar->start();

foreach ($records as $record) {
    $this->processRecord($record);
    $progressBar->advance();
}

$progressBar->finish();
$this->newLine();
```

## Ejecución Programada

### Configuración en Kernel
```php
// app/Console/Kernel.php
protected function schedule(Schedule $schedule)
{
    // Actualizar saldos diariamente
    $schedule->command('gw:update.balance')
        ->daily()
        ->withoutOverlapping()
        ->appendOutputTo(storage_path('logs/balance-update.log'));

    // Sincronizar cotizaciones cada hora
    $schedule->command('gw:currency.sync')
        ->hourly()
        ->runInBackground();

    // Limpieza semanal
    $schedule->command('gw:clear')
        ->weekly()
        ->sundays()
        ->at('02:00');
}
```

### Ejecución Manual
```bash
# Ejecutar comando específico
php artisan gw:update.balance

# Con parámetros
php artisan gw:update.balance 1 --chunk-size=100

# En segundo plano (Linux/Unix)
nohup php artisan gw:migrate.from-pgsql > /dev/null 2>&1 &

# Con timeout (Linux/Unix)
timeout 3600 php artisan gw:update.balance
```

## Trait CommandTrait

### Funcionalidades Incluidas
```php
trait CommandTrait
{
    // Configuración de memoria
    protected function setMemoryLimit(string $limit): void
    {
        ini_set('memory_limit', $limit);
        $this->info("Límite de memoria establecido: {$limit}");
    }

    // Información del sistema
    protected function showSystemInfo(): void
    {
        $this->info("Memoria actual: " . memory_get_usage(true));
        $this->info("Memoria pico: " . memory_get_peak_usage(true));
    }

    // Validación de empresa
    protected function validateCompany(int $companyId): Company
    {
        $company = Company::find($companyId);
        if (!$company) {
            throw new InvalidArgumentException("Empresa no encontrada: {$companyId}");
        }
        return $company;
    }
}
```

## Ejemplos de Uso

### Comando Básico
```bash
# Actualizar saldos de todas las empresas
php artisan gw:update.balance

# Actualizar saldos de empresa específica
php artisan gw:update.balance 1

# Con configuración específica
php artisan gw:update.balance --chunk-size=200 --memory-limit=1G
```

### Comando con Filtros
```bash
# Actualizar cliente específico
php artisan gw:update.balance --customer=100

# Actualizar factura específica
php artisan gw:update.balance --id=500
```

### Migración Completa
```bash
# Migrar desde PostgreSQL
php artisan gw:migrate.from-pgsql --chunk-size=100

# Validar migración
php artisan gw:migration.validate

# Limpiar datos temporales
php artisan gw:clear --force
```
