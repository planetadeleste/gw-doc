## 1. Configuración de la Empresa Principal

### Acceder a la Configuración

1. Ingresa al backend: `https://tu-dominio.com/backend`
2. Ve a **GW > Empresas**
3. Haz clic en **Nueva Empresa**

### Datos Básicos Requeridos

<CardGroup cols={2}>
  <Card title="Información Fiscal" icon="receipt">
    - RUT/CUIT/NIT de la empresa
    - Razón social completa
    - Nombre comercial
    - Domicilio fiscal
  </Card>
  <Card title="Información de Contacto" icon="phone">
    - Teléfono principal
    - Email de contacto
    - Sitio web
    - Redes sociales
  </Card>
</CardGroup>

### Formulario de Empresa

```javascript
// Ejemplo de datos básicos
{
  "name": "Mi Empresa S.A.",
  "commercial_name": "Mi Empresa",
  "rut": "123456789012",
  "address": "Av. Principal 123",
  "city": "Montevideo",
  "country": "Uruguay",
  "phone": "+598 2 123 4567",
  "email": "contacto@miempresa.com",
  "website": "https://miempresa.com"
}
```

### Configuraciones Específicas

#### Configuración Fiscal
- **Condición ante impuestos**: Responsable Inscripto / Exento
- **Actividad económica principal**
- **Fecha de inicio de actividades**
- **Período fiscal**: Enero-Diciembre / Julio-Junio

#### Configuración Contable
- **Moneda base**: Peso Uruguayo (UYU) / Dólar (USD)
- **Método de valuación**: FIFO / LIFO / Promedio
- **Cierre de ejercicio**: 31/12 / 30/06

### Configuración por País

#### Uruguay (CFE)
- **Factura de Contado**: Código 101, Serie A
- **Factura de Crédito**: Código 111, Serie A
- **Nota de Crédito**: Código 102, Serie A
- **Nota de Débito**: Código 103, Serie A
- **e-Ticket**: Código 121, Serie A

#### Argentina (AFIP)
- **Factura A**: Código 001, IVA Responsable Inscripto
- **Factura B**: Código 006, Consumidor Final
- **Factura C**: Código 011, IVA Exento
- **Nota de Crédito A**: Código 003
- **Nota de Débito A**: Código 002

## 7. Configuración de Facturación Electrónica

### Certificados Digitales (Uruguay)

1. Obtener certificado de AGESIC
2. Convertir a formato .p12
3. Subir en **Empresa > Configuración > Certificados**

```bash
# Convertir certificado .crt y .key a .p12
openssl pkcs12 -export -out certificate.p12 \
  -inkey private.key -in certificate.crt \
  -certfile ca-chain.crt
```

### Configuración DGI

```php
// En configuración de empresa
'dgi_settings' => [
    'environment' => 'production', // o 'testing'
    'webservice_url' => 'https://efactura.dgi.gub.uy/',
    'certificate_path' => storage_path('certificates/company.p12'),
    'certificate_password' => 'password_del_certificado',
    'timeout' => 30
]
```

### Prueba de Conectividad

```bash
# Verificar conectividad con DGI
php artisan gw:dgi.test-connection --company=1

# Firmar factura de prueba
php artisan gw:invoice.sign 1 --test
```

## Configuración Avanzada

### Performance y Cache

```bash
# Configurar cache para consultas frecuentes
php artisan config:publish October.Drivers.Cache

# Configurar Redis para cache
CACHE_DRIVER=redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
```

### Configurar Colas

```bash
# Configurar cola para procesamiento asíncrono
QUEUE_CONNECTION=database

# Crear tabla de trabajos
php artisan queue:table
php artisan migrate

# Iniciar worker
php artisan queue:work
```

### Monitoreo

```bash
# Configurar logs específicos
'channels' => [
    'gw' => [
        'driver' => 'daily',
        'path' => storage_path('logs/gw.log'),
        'level' => 'info',
        'days' => 30,
    ],
]
```
