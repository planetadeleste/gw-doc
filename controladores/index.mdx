# Controladores

Los controladores del plugin PlanetaDelEste.GW proporcionan la interfaz de administración en el backend de OctoberCMS. Cada controlador maneja las operaciones CRUD y funcionalidades específicas de su dominio.

## Estructura General

Todos los controladores siguen las convenciones de OctoberCMS y extienden la clase base `Backend\Classes\Controller`:

```php
use Backend\Classes\Controller;
use BackendMenu;

class ExampleController extends Controller
{
    public $implement = [
        'Backend\Behaviors\ListController',
        'Backend\Behaviors\FormController'
    ];

    public $listConfig = 'config_list.yaml';
    public $formConfig = 'config_form.yaml';

    public function __construct()
    {
        parent::__construct();
        BackendMenu::setContext('PlanetaDelEste.GW', 'menu-item');
    }
}
```

## Behaviors Implementados

### ListController
Proporciona funcionalidad de listado con:
- Filtros avanzados
- Búsqueda
- Paginación
- Ordenamiento
- Exportación

### FormController
Permite creación y edición con:
- Validación automática
- Relaciones
- Campos personalizados
- Eventos del formulario

### ImportExportController
Para controladores que manejan importación/exportación:
- Importación desde CSV/Excel
- Exportación a múltiples formatos
- Validación de datos
- Procesamiento por lotes

## Permisos y Seguridad

### Definición de Permisos
```php
// En plugin.yaml
permissions:
    gw-menu-examples:
        label: 'Gestionar ejemplos'
        tab: 'GW'
```

### Verificación en Controlador
```php
public function __construct()
{
    parent::__construct();

    // Verificar permisos
    $this->requiredPermissions = ['gw-menu-examples'];

    // Establecer contexto del menú
    BackendMenu::setContext('PlanetaDelEste.GW', 'gw-menu-main', 'gw-menu-examples');
}
```

## Métodos Personalizados Comunes

### Filtros por Empresa
```php
public function listExtendQuery($query)
{
    // Filtrar por empresa del usuario logueado
    if ($companyId = $this->getCurrentCompanyId()) {
        $query->where('company_id', $companyId);
    }
}

protected function getCurrentCompanyId(): ?int
{
    // Lógica para obtener la empresa actual
    return session('current_company_id');
}
```

### Validaciones Personalizadas
```php
public function formValidate($model, $form)
{
    // Validaciones específicas del controlador
    $rules = [
        'code' => 'required|unique:table_name,code,' . $model->id,
        'name' => 'required|string|max:255'
    ];

    $validator = Validator::make($form->getSaveData(), $rules);

    if ($validator->fails()) {
        throw new ValidationException($validator);
    }
}
```

### Acciones Personalizadas
```php
public function onCustomAction()
{
    // Validar permisos
    if (!$this->user->hasPermission('gw-menu-examples.custom_action')) {
        throw new ForbiddenException();
    }

    // Procesar acción
    $selectedIds = post('checked');
    foreach ($selectedIds as $id) {
        $model = ExampleModel::find($id);
        $model->performCustomAction();
    }

    Flash::success('Acción ejecutada correctamente');
    return $this->listRefresh();
}
```

## AJAX Handlers

### Autocompletado
```php
public function onSearchItems()
{
    $term = input('term');
    $items = ExampleModel::where('name', 'like', "%{$term}%")
        ->limit(10)
        ->get(['id', 'name']);

    return $items->map(function ($item) {
        return [
            'id' => $item->id,
            'text' => $item->name
        ];
    });
}
```

### Carga Dinámica
```php
public function onLoadRelatedData()
{
    $parentId = input('parent_id');
    $children = ChildModel::where('parent_id', $parentId)->get();

    return [
        'options' => $children->pluck('name', 'id')->toArray()
    ];
}
```

## Ejemplos de Implementación

### Controlador Básico
```php
<?php namespace PlanetaDelEste\GW\Controllers;

use Backend\Classes\Controller;
use BackendMenu;

class Examples extends Controller
{
    public $implement = [
        'Backend\Behaviors\ListController',
        'Backend\Behaviors\FormController',
        'Backend\Behaviors\ImportExportController'
    ];

    public $listConfig = 'config_list.yaml';
    public $formConfig = 'config_form.yaml';
    public $importExportConfig = 'config_import_export.yaml';

    public $requiredPermissions = ['gw-menu-examples'];

    public function __construct()
    {
        parent::__construct();
        BackendMenu::setContext('PlanetaDelEste.GW', 'gw-menu-main', 'gw-menu-examples');
    }

    public function formBeforeSave($model)
    {
        // Establecer empresa actual
        if (!$model->company_id) {
            $model->company_id = $this->getCurrentCompanyId();
        }
    }

    public function listExtendQuery($query)
    {
        // Filtrar por empresa
        if ($companyId = $this->getCurrentCompanyId()) {
            $query->where('company_id', $companyId);
        }
    }
}
```

## Mejores Prácticas

<Tip>
**Seguridad**: Siempre verifica permisos antes de ejecutar acciones sensibles.
</Tip>

<Warning>
**Validación**: Implementa validaciones tanto en el modelo como en el controlador.
</Warning>

<Info>
**Performance**: Usa eager loading en consultas que incluyen relaciones.
</Info>

Los controladores son la capa de presentación del sistema y deben mantener la lógica de negocio en los modelos correspondientes.
